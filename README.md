# ShoppingCart

This C# project implements a basic shopping cart system, featuring Object-Oriented Programming (OOP) principles such as encapsulation and modular design. The project includes classes to manage products and calculate totals, discounts, and taxes. It also comes with comprehensive unit tests to ensure functionality, using the Arrange-Act-Assert (AAA) pattern. This project demonstrates a solid grasp of OOP, code structure, and automated testing.

The Shopping Cart was created in Visual Studio.
