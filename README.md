# 🛒 Shopping Cart System

## 🚀 Project Overview and Learning Outcomes

This project focuses on implementing a basic shopping cart system using C#. It includes functionality to manage products, calculate totals, apply discounts, and handle taxes. The design follows Object-Oriented Programming (OOP) principles, ensuring a clear separation of concerns with modular and encapsulated code. Additionally, unit tests are written using the **Arrange-Act-Assert (AAA)** pattern to verify the correctness of the system's operations.

---

## ✨ Features

- **🛍️ Product Management:** Add, remove, and display products in the shopping cart.
- **💲 Total Calculation:** Automatically calculate total costs, including discounts and taxes.
- **🎯 Discount and Tax Handling:** Apply discounts and taxes to the cart's total based on predefined rules.
- **🧪 Unit Testing:** Ensure code reliability with comprehensive tests using the AAA pattern.

---

## 🛠️ How to Use

1. **Add Products:** Add products by specifying their names, prices, and quantities.
2. **Apply Discounts and Taxes:** The system will automatically apply any applicable discounts and taxes.
3. **View Total:** View the total cost, including taxes and discounts.

---

### 📊 Example Usage

- **Add Products:**
  Add items like `Apple - $1.50` and `Banana - $0.99` to the shopping cart.
  
- **Apply Discounts:**
  Apply a 10% discount on the total.
  
- **Calculate Total:**
  After taxes and discounts, the total will be displayed as `$2.23`.
