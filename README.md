# 🛒 Shopping Cart System - Coding Assessment

## 🚀 Project Overview and Learning Outcomes

This project was part of a coding assessment for a placement opportunity, where I was tasked with building a **Shopping Cart System** in C#. The application is designed to manage products, calculate totals, apply discounts, and handle taxes. The inputs and requirements were predefined by a senior developer, and the program calculates the final total without needing any user interaction. 

The project follows **Object-Oriented Programming (OOP)** principles, ensuring modularity and encapsulation. What really excited me about this project was learning and applying **unit testing**. I used the **Arrange-Act-Assert (AAA)** pattern to validate that each aspect of the shopping cart worked as expected. The idea that you could not only write code but also test its correctness in one go opened my eyes to how powerful and efficient proper testing can be! It was incredible to see my code run and get real-time feedback on its reliability.

---

## ✨ Features

- **🛍️ Product Management:** Handles predefined products, calculates totals, and applies necessary discounts and taxes.
- **💲 Automated Total Calculation:** Automatically calculates the final cost, including discounts and taxes, based on predefined inputs.
- **🧪 Unit Testing:** Implemented robust unit tests using the **AAA pattern** to ensure code accuracy and reliability.
